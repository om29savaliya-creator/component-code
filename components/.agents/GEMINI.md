# Electronics Lab Project — Coding Rules

## Always Discuss Before Coding
For this project, NEVER write code for a new feature or structural change
without first discussing the design/idea with the user and getting explicit
approval to proceed. The workflow must always be:
  1. Analyze / understand the request
  2. Propose the design idea in plain words
  3. Wait for user confirmation
  4. Then write the code

## Respect Electronics Fundamentals
This is a real-world electronics simulation. Always reason from correct
electronics principles (KVL, KCL, Ohm's Law, node analysis) before proposing
any model or behavior. Do not oversimplify circuit behavior.
